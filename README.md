# Boom Karts

3D arcade kart racer. Drift, items, AI race, time trial, Coral Cup.

## Run

```bash
npm install
npm run dev
```

Open the URL shown (default `http://localhost:8080`).

## Controls

| Key | Action |
|---|---|
| W / ↑ | Accelerate |
| S / ↓ | Brake |
| A D / ← → | Steer |
| Space | Drift (hold then release for mini-turbo) |
| E | Item |
| Esc | Pause |

Mobile: on-screen stick + drift/item buttons.

## Modes

- **Race** — 6 karts, 3 laps
- **Time Trial** — solo, saves best time
- **Coral Cup** — Coral Coast → Dune Loop → Ridge Run

Best times are stored in the browser.
